# Breast Cancer Tumor Segmentation using U-Net and GMM

This Streamlit application allows users to upload breast cancer mammogram images and automatically segment tumor regions using a **U-Net deep learning model**, refined with **Gaussian Mixture Model (GMM)**. The app also provides a trustworthiness score for the prediction and visual analysis of tumor areas.

---

## Features

- Upload mammogram images for tumor detection.
- Preprocess images (grayscale conversion and resizing).
- Tumor segmentation using a pre-trained **U-Net model**.
- Refinement of segmentation masks using **Gaussian Mixture Model (GMM)**.
- Visual comparison of original image, initial U-Net mask, and refined mask.
- Graphical analysis of tumor percentage and trustworthiness score.
- Trustworthiness score on a scale of 1–10.

---

## Problem Statement

Breast cancer detection is crucial for early diagnosis and treatment. Deep learning models like U-Net can analyze mammogram images and segment tumor regions with high accuracy, aiding radiologists in diagnosis.
